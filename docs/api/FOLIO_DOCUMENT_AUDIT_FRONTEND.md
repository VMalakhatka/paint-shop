# Независимый аудит денежных документов ФОЛИО

Разработка 2026-09-09. WordPress `lavka-reports` 0.4.0; Java rulesVersion
`2026-09-09.1`. Не задеплоено в рамках этой разработки.

## Владельцы и контракт

Java — выборка всех SCL_PLAT по включительному диапазону реальных дат, категория,
проверки обязательных полей и версии правил. WordPress — закрытый интерфейс,
контроль пагинации, фильтры и Excel; не пересчитывает прибыль и не меняет ФОЛИО.
Канонический контракт находится в Java-проекте:
`docs/api/FOLIO_DOCUMENT_AUDIT_API.md`.

`GET /admin/folio/document-audit`: dateFrom/dateTo, pageSize=200,
afterPaymentId, upperPaymentId, expectedRulesVersion. Даты максимум 366 дней.
WordPress AJAX `lavr_document_audit` доступен только с `manage_woocommerce`
и собственным nonce. Токен Java добавляется сервером, браузер его не получает.

Успех: `ok=true,status=PAGE_READY,rulesVersion,dateFrom,dateTo,calculatedAt,
coverage,page,summary,rules,items`. Ключ пагинации **page**, не pagination.
Направления INCOMING/OUTGOING/UNKNOWN. Статусы VALID/ERROR/RULE_REVIEW;
неизвестный будущий статус отображается с исходным кодом в фильтре RULE_REVIEW.
Классификация и статус независимы.

`summary.scope=PAGE` не является итогом всех страниц. UI считает число
полученных строк и статусов, сверяет уникальные возрастающие paymentId,
upperPaymentId, rulesVersion, даты, курсор и examined. Завершение без совпадения
числа строк и totalDocuments остаётся неполным. Правила/период/границы нельзя
подменять посреди загрузки. Ошибка следующей страницы сохраняет предыдущие.

## Отображение и экспорт

Три статуса; поиск и фильтры по категории/статусу, локальные страницы по 50 строк.
Ошибка и рекомендация стоят рядом с категорией. Полные поля: дата/номер/ID,
касса/банк, приход/расход, склад, SUM_POR, raw COD_VALUT и статус единицы суммы,
краткое/полное имя организации, назначение, тип операции, IST_INF, примечание,
период, маскирование, распознавание, учёт в прибыли и ссылки на правила.

Суммы **не складываются и не конвертируются**: COD_VALUT не доказывает валюту
SUM_POR. NULL не превращается в ноль. Excel сохраняет все загруженные документы
независимо от экранного фильтра, отдельные листы замечаний, правил и паспорта.
Текст, похожий на формулу, остаётся текстом. Неполный файл имеет suffix `-partial`.
Изменение дат блокирует экспорт до нового запуска, останавливает текущую загрузку.

Пагинация LIVE_NOT_SNAPSHOT: верхний ID ограничивает новые документы, но не
защищает от редактирования/удаления прочитанного. Паспорт содержит это ограничение.
Полнота загруженных страниц и полнота правил — разные показатели.

## Область v1 и дальнейшие проверки

Все кассовые/банковские документы, оба направления, все склады за даты.
Накладные, сверка пар переводов, банковской выписки, исторических касс и реальных
контрагентов пока не реализованы, явно перечислены в coverage.unsupported.
Отсутствующий sourceInfo зарплаты — ошибка качества; прибыль не меняется.
`№1`, `№2`, `№1 и Н`, неоднозначные операции/условия — реестр уточнения правил.
Функции автоматического исправления/утверждения новых правил отсутствуют.

Исходник «ПРАВИЛА ВНЕСЕНИЯ движения денег.xls» содержит реквизиты; не включён в Git.
Скилл `folio-document-rules` содержит только обезличенные правила и происхождение.
Лист справочников с01.09.2026 не применяется автоматически к июлю.

## Включение и проверка

Java по умолчанию отключает новый endpoint:
`LAVKA_FOLIO_DOCUMENT_AUDIT_ENABLED=false`. Перед включением ограничить прямой
доступ к API через существующий admin/proxy/VPN-контур. Полные примечания
содержат частные финансовые сведения; WordPress nonce не защищает прямой Java URL.
UI объясняет DOCUMENT_AUDIT_DISABLED. Контракт SOURCE_UNAVAILABLE не показывает
пустой результат как подтверждённое отсутствие документов.

Тесты: `tests/document-audit-proxy.php`, `tests/document-audit.spec.cjs` в lavka-reports.
Сценарии: capability/nonce/даты, все страницы, salary error, дубли/версия/сбой,
неизвестный статус, пустой результат, смена дат, безопасный текст и Excel.
Инструкция оператора: [runbook](../OPERATIONS_RUNBOOK.md#аудит-документов-фолио).
