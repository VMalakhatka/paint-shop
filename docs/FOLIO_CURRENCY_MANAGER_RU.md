# Менеджеру: «Валютная цена Украина»

Проверено: 22.10.2026 по подготовленному интерфейсу. Функция и справка пока **не опубликованы на рабочем сайте**.

После публикации откройте **Лавка ФОЛИО → Валютная цена Украина**. Функция меняет валютную цену и код валюты карточек на всех складах, а дополнительную цену **ЯЯ_Р_ВАЛЮТ** — только на складе **7**. Оба изменения сохраняются вместе.

1. **Подготовьте файл Excel или CSV** с тремя колонками:

   | CODE_ARTIC — артикул | PRICE — валютная цена | KOD_VALUT — код валюты |
   |---|---:|---|
   | ML-47068 | 1,8987 | 3 |
   | ML-18270 | 1,6974 | 3 |

   Шапка необязательна. Если она есть, названия должны быть ровно `CODE_ARTIC`, `PRICE`, `KOD_VALUT`. Порядок колонок сохраняйте. Excel: первый лист, значения без формул. CSV: UTF-8; удобнее разделитель `;`. Допустимы `1,8987` и `1.8987`. До **5 МБ и 500 уникальных артикулов**.

2. **Выберите файл → «Посмотреть изменения».** Это только чтение. Проверьте имя файла, артикулы, склады, старые и новые цены, коды валют. `SCL_ARTC` — карточки; `SCL_PRIC` — дополнительная цена. Один артикул может дать несколько строк по складам. Проверьте оба списка отсутствующих позиций: они будут пропущены, новые карточки и строки цен не создаются.

3. **Отметьте подтверждение → «Применить в ФОЛИО».** Предпросмотр действует **15 минут**. Если данные изменились или срок истёк, выполните новый просмотр и проверьте его. Дождитесь сообщения **«Оба обновления сохранены и проверены»**.

4. **Если связь пропала — «Проверить статус».** После обновления страницы откройте операцию в **«Последних операциях»**. Пока результат неизвестен, **не загружайте файл повторно**. Если статус не проясняется, передайте администратору имя файла и время операции. Если ошибочные цены уже сохранены, также обратитесь к администратору: автоматической отмены нет.

На странице доступны **«Краткая инструкция менеджеру»** с примером файла и раскрывающиеся подсказки рядом с каждым этапом. Они открываются без запуска операции.
