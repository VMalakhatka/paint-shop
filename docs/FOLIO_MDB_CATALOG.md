Извлечение выполнено офлайн через mdbtools и Jackcess readOnly, без исполнения SQL, макросов или обращения к связанным таблицам. Хеш исходника после чтения совпадает. Структура skill, охват 33 запросов и 9 макросов и отсутствие вероятных секретов проверены.

Существенные результаты анализа: у `Валютная_Цена_Плюс` нет фильтра склада; запросы `Учётная_Цена_*` являются SELECT; «Неправильная Валютная Цена» отбирает ненулевое в смысле NOT NULL поле без проверки правильности; источник `dbo_SCL_ARTC-BB` отсутствует среди связей файла. Эти особенности не исправлялись. Плановые APPEND формируют локальные списки, а создание документов движения ими не подтверждено.

## Два новых MDB

Все 684 запроса восстановлены без ошибок извлечения SQL. В каждой карточке сохранены поля/присваивания, источники и их виды, параметры, JOIN/WHERE и полный Access SQL. Источники из метаданных найдены среди объектов соответствующего файла; работоспособность связанных таблиц на сервере этим не проверяется. Файлы исследованы офлайн, их SHA-256 после чтения не изменились. Исходные MDB, рабочие данные и строки подключения в skill или Git не переносились.

В `Запросы_из_Фолио-TS.mdb` есть массовые изменения карточек/цен и 12 DELETE связанных записей, включая удаление конкретного Key. В `Розница-TS.mdb` есть расчёт розницы, промежуточная Price, разборки, конвертация валют, четыре DELETE и два CREATE TABLE. Название `ОПТ+3%` в одном UPDATE соответствует коэффициенту 0.97; это сохранено как исходная логика, без исправления. Предметные разборы с точными именами запросов находятся в skill.

Все 55 новых макросов зарегистрированы, но их определения не извлечены (`UNRESOLVED_STORAGE`): формат первого MDB через MSysAccessStorage здесь не доступен. Нельзя считать имена запросов подтверждением последовательности исполнения. В `Розница-TS.mdb` обнаружен `Module1`, тело не извлечено; SQL вызывает `okrugl(...)`, определение которой ещё нужно получить. Её принадлежность именно Module1 пока не установлена.

## Что ещё требуется

Для каждого нового объекта источник загрузки входных данных и условие запуска ожидают пояснений владельца. Для полного разбора макросов нужен текстовый экспорт их определений из Access; бинарные упоминания запросов не доказывают цепочку исполнения. Для розничных формул дополнительно нужен экспорт VBA и определение `okrugl`. Процедура безопасного экспорта сохранена в skill, `references/offline-extraction.md`. Новые функции сайта по этим двум MDB не реализовывались.

Новые MDB добавляются по имени и хешу отдельными версиями. Их содержимое — источник анализа, а не разрешение выполнять операции. 22.10.2026 по отдельному подтверждению владельца подготовлена [реализация «Валютная цена Украина»](api/FOLIO_CURRENCY_UA.md): Excel/CSV → предпросмотр → оба исходных UPDATE одной транзакцией. Production-публикация и живые UPDATE не выполнялись. Остальные функции не реализованы. Ранее созданная функция экспорта карточек является отдельной работой.
