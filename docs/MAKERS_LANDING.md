# Лендинг «Для майстрів»

Проверено: 2026-11-03. Владелец предложения — владелец Лавки; технический владелец —
контент WordPress и существующий public-page renderer `paint-shop-ux`.

## Назначение и содержание

Отдельная украинская страница для мастеров, творческих мастерских, авторских
изделий и небольших серий. Основное действие — написать о своей работе,
нужных материалах и объёмах, затем согласовать индивидуальную скидку.
Фиксированный процент, минимальный заказ и автоматическая оптовая роль не обещаны.

Четыре направления ведут в действующий каталог: стекло/контуры, керамика/фарфор,
текстиль и Cernit. Дополнительные ссылки ведут к кистям, лакам/грунтам, основам
и инструментам. Шесть предоставленных владельцем фотографий показывают изделия
и материалы; они не являются отзывами, обязательным ассортиментом в наличии
или доказательством совместимости всех показанных составов.

Основная кнопка ведёт в `https://kreul.com.ua/my-account/?pcoe_chat=1`.
Новый посетитель регистрируется или входит, затем создаёт «Нове звернення»
в «Повідомленнях», выбирает «Загальне питання» и тему «Співпраця з майстром».
Регистрация и чат включены (оба production options `yes`, проверено 2026-11-03).
Гостевая страница показывает вход и регистрацию; сообщения допускают обычную роль
`customer` по `ConversationStore::customer()`. Перепиской и её приватностью
владеет существующий PCOE, лендинг только направляет пользователя в кабинет.
Новый аккаунт и пробное сообщение при проверке не создавались.

По уточнению владельца запасной канал — `shop@paint.dn.ua`. Email-кнопка открывает
почтовое приложение с темой и заготовкой письма; пользователь сам отправляет его.
В кабинете поддерживается текст: фотографии предлагается отправлять на email,
а ссылки на работы можно вставить в сообщение. Телефон оптовых продаж взят с сайта.
Регистрация не назначает скидку автоматически; скидку согласовывает менеджер.
Лендинг не меняет роли, правила регистрации/чата, рассылки или оптовый заказ.
Опубликованная справка «Як замовляти» уже описывает сообщения (`#messages-new`);
этот контентный вход не меняет её действия и не требует deploy справки.

## Источники и оформление

Исходники: [`content/makers-landing`](../content/makers-landing/README.md).
Текст — `page.html`, оформление — `style.css`, фотографии — `assets/`.
Сборка создаёт один `core/html` блок с ограниченными селекторами CSS.
Шапка, каталог, корзина и подвал принадлежат обычной теме сайта.

CSS с `body:has(.lavka-makers)` снимает ограничения ширины карточки и скрывает
дублирующий заголовок именно этой страницы. Сам лендинг содержит один H1.
В браузере без `:has()` контент доступен, но может оставаться узкая внешняя карточка
и дублирующий заголовок. FAQ работает через native `details`; JavaScript не нужен.

Содержимое страницы, заголовок и описание Rank Math, а также социальное фото
записываются в эту страницу. Общие SEO-настройки не меняются. Featured image
не назначается, чтобы тема не дублировала первое фото над лендингом.

## Выпуск и безопасное продолжение

1. Собрать локальное представление и проверить текст, фото, контакты, мобильный
   и настольный вид. Все относительные `assets/` в release должны замениться
   реальными HTTPS URL медиатеки.
2. Передать подготовленный bundle в закрытую папку вне web-root через SSH alias
   `kreul`; реквизиты подключения не входят в репозиторий.
3. Через WP-CLI выполнить `wordpress.php preview <bundle-dir>` с редактором,
   имеющим `edit_pages`, `upload_files`, `unfiltered_html`.
4. `prepare` создаёт только новую страницу-черновик и шесть editorial attachments
   через WordPress `media_handle_sideload`. Обычные Media Cloud hooks сохраняются.
   Товары, категории, клиенты, цены, меню, база целиком и глобальные options
   не перезаписываются. Общий deploy плагинов для контентной операции не нужен.
5. `verify` сравнивает весь сохранённый контент с bundle и возвращает ID/URL.
   Проверить HTTPS-фотографии и предпросмотр в текущей теме.
6. `publish` — отдельная явная стадия после проверки и в рамках разрешённой
   владельцем публикации; требуется `publish_pages`. Затем проверить публичный
   HTTP 200, canonical, meta robots, title/description, картинки и mobile.

CLI helper намеренно привязан к `kreul.com.ua` и slug `dlia-maistriv`, не является
плагином и не должен находиться в web-root. Slug с чужим release marker не
перезаписывается. Опубликованная страница не принимается в `prepare`.
Для разрешённого изменения опубликованной страницы режим `update` требует
третьим аргументом точный SHA256 текущего контента; перед записью сохраняет
закрытый JSON backup страницы и её meta в bundle-dir (0600). Несовпадение хеша
останавливает запись. После обновления снова проверить публичную страницу.

Не повторять `prepare` автоматически после потери соединения. Сначала сверить
страницу и attachments: `_lavka_makers_release=makers-landing-20261103`,
`_lavka_makers_asset`, `_lavka_makers_sha256`. Если соединение потеряно между
созданием attachment и записью marker, проверить также имена
`lavka-makers-20261103-*.jpg` и время загрузки. Дубли вручную согласовать;
удаление изображений/объектов не является автоматическим rollback.

## Проверка и восстановление

Локальная приёмка: PHP lint, сборка без незаполненных placeholders, все девять
уникальных ссылок каталога HTTP 200, шесть изображений загружены, один H1,
работают якорь контактов, FAQ и mailto, нет горизонтального переполнения
на 320, 390 и 1440 px. Локальная база WordPress не была запущена; это не
выдаётся за локальную проверку темы. Тема проверяется на серверном preview.

Для отката видимости вернуть только новую страницу в «Черновик»; фото остаются
в медиатеке. Исходные фотографии владельца не изменялись. Откат Git не меняет
контент в БД. Платные рекламные кампании в эту работу не входят.

## Вход через подвал: «Співпраця» (2026-11-05)

Подготовлен раскрывающийся пункт **«Співпраця» → «Для майстрів»** в общем
подвале сайта: каталог и кабинет остаются рядом. На телефоне список открывается
внутри подвала, на компьютере — под названием. Нативный `details/summary`
работает по нажатию, Enter и Space, без дополнительного JavaScript.

Владелец — `paint-shop-ux/inc/site-footer.php` и `assets/site-footer.css`.
Без назначенного меню показывается опубликованная, не защищённая паролем
страница со slug `dlia-maistriv`. ID страницы не фиксируется. Если страницы нет
или она скрыта, пустой пункт не выводится.

Для добавления страниц опта, школ и студий:

1. Создать и опубликовать соответствующие страницы.
2. В WordPress открыть «Вигляд → Меню», создать меню сотрудничества.
3. Добавить страницы обычными пунктами верхнего уровня, включая «Для майстрів».
4. Назначить область **«Посилання співпраці (підвал)»** (`psu-cooperation`).

Название и порядок берутся из этого меню. Вложенные пункты, произвольные ссылки,
черновики, закрытые и защищённые паролем страницы не выводятся. Назначенное меню
без допустимых страниц скрывает раздел. Несуществующие страницы не рекламируются.
