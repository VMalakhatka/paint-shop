# Lavka / KREUL

Рабочий репозиторий WordPress/WooCommerce для `paint.local` и `kreul.com.ua`.
Сайт связан с собственными PHP-плагинами, Java API, ФОЛИО на legacy MS SQL,
MariaDB, OVH/S3, платёжными и логистическими сервисами.

## Границы репозиториев

- Этот репозиторий владеет WordPress/WooCommerce, собственными PHP-плагинами,
  темой, WordPress-конфигурацией и application deploy сайта.
- Репозиторий `kreul_com_ua` владеет Java API, контрактами ФОЛИО и вторичной
  MariaDB-проекцией аналитики.
- ФОЛИО/MS SQL остаётся отдельной учётной системой. Наличие Java endpoint не
  переносит бизнес-данные или транзакцию ФОЛИО в WordPress.
- Host, Windows VM, MSSQL runtime и резервирование сервера описываются отдельно от
  deploy WordPress и Java.

## Правила безопасности

- Не хранить в Git или документации пароли, токены, ключи, connection strings,
  внутренние адреса и персональные данные. Указывать только имена переменных,
  безопасные defaults и способ проверить факт настройки.
- Обычный deploy кода не заменяет production-базу и не активирует новый `manual`
  plugin автоматически.
- Любая массовая синхронизация использует общий ecosystem lock. После timeout или
  неизвестного результата сначала проверяется статус; мутирующий запрос не
  повторяется вслепую.
- Финансовые, документные, фискальные, логистические и production-операции записи
  требуют отдельного явного подтверждения после preview и проверки восстановления.

Корневой README служит только безопасным индексом. Конкретные операционные команды,
критерии успеха и rollback живут в соответствующих runbooks, а секреты — только во
внешней или ignored environment-конфигурации.
